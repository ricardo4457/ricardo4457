<summary>How it is built</summary>
<br />

- **Scraper:** Node.js with Playwright, and BullMQ job queues on Redis
- **API:** Laravel, with asynchronous scraping requests and token-secured communication between services
- **Frontend:** Vue 3, with a step-by-step search form and an interactive map of Portugal
- **Infrastructure and testing:** Docker Compose to run everything, with tests across all three layers (Vitest, Jest and Pest)
